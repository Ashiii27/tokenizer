    § 05b — the same corpus, flattened

    The map PCA · 384d → 2d

    Nobody can picture 384 dimensions. Project the corpus down to two with principal component analysis and semantically similar sentences land near each other. Hover a point to read it; click to select it in the matrix above.

    Embed the corpus above and the map appears here.

    What you’re looking at

    • Retrieval is ranking by cosine. That is the whole of semantic search, minus the index.
    • The matrix is symmetric and every vector is unit-normalised, so the diagonal is always 1.0.
    • The first run downloads about 23 MB of model; after that a corpus of this size embeds in a second or two.
