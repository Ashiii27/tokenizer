§ 03 — the cost of language

One meaning,
seven languages GPT-2

The same sentence, translated. Tokenizers trained mostly on English spend far more tokens on other scripts: Devanagari, Bengali, Tamil and Han characters are three bytes each and often get shredded into several tokens per character.

Try this

  1. Measure with GPT-2 first, then switch to Llama 3 — a far larger vocabulary trained on more non-English text.
  2. Watch characters-per-token fall below 1. That means a single character spans several tokens.
  3. Compare the cost column: the same meaning can bill four to six times more in Hindi than in English.

What you’re looking at

  • Cost is measured against English for the same sentence, not for the same number of characters.
  • This is the arithmetic behind the observation that multilingual products cost more to run for identical content.
  • Tokenization is not the whole story of model quality, but it sets the floor on price and on how much context a language gets.
