1 Tokens and token IDs

Xenova/gpt2

A tokenizer splits text into pieces — whole words, word fragments, single bytes — and maps each piece to an ID from a fixed vocabulary. Those IDs are the only thing the network ever reads. Try Hindi, Chinese or an emoji: watch how one character splits into several tokens.

              4 Meaning as a vector
            

            all-MiniLM-L6-v2 · 384d
          

          

            An embedding model squeezes a whole sentence into 384 numbers. Similar meanings end up with
            similar numbers, so the angle between two vectors — cosine similarity —
            becomes a measure of how close in meaning two texts are.

              6 The meaning map
            
    
            PCA · 384d → 2d
          
    
          
    
            Embeddings live in 384 dimensions, which nobody can picture. Project the corpus down to two
            with principal component analysis and semantically similar sentences land near each other.
            Hover a point to read it. This is the same projection behind every "embedding space" chart
            you have seen.
